# create-sorapaper-astro-theme

Create a standalone, editable SoraPaper Astro blog:

```bash
npm create sorapaper-astro-theme@latest my-blog
```

Then start the site:

```bash
cd my-blog
pnpm install
pnpm dev
```

The generated project owns its configuration, content and dependencies. It is
not coupled to this initializer after creation.
