# Changelog

All notable changes to SoraPaper are documented in this file.

## 1.0.1 - 2026-07-17

### Added

- A `create-sorapaper-astro-theme` CLI package for initializing a standalone
  SoraPaper site with `npm create sorapaper-astro-theme`.

### Changed

- Published template packages exclude repository documentation and development
  files.

## 1.0.0 - 2026-07-16

### Added

- Public npm package metadata, package-content allowlist and release checks.
- MIT license and npm installation and release documentation.

### Included

- The Astro blog theme source, public assets, sample content and user-facing
  configuration documentation.
